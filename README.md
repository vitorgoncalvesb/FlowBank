# FlowBank Landing Page

Landing page responsiva da FlowBank, construída com React, TypeScript e Vite.

## Stack

- React
- TypeScript
- Vite
- CSS responsivo
- Lucide React

## Requisitos

- Node.js 18+
- npm 9+

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

A aplicação ficará disponível no endereço exibido pelo Vite, normalmente `http://localhost:5173`.

## Build de produção

```bash
npm run build
```

## Preview da build

```bash
npm run preview
```

## Estrutura

```text
src/       Código React e estilos
public/    Assets públicos
index.html Entrada HTML
vite.config.ts Configuração do Vite
```

## Deploy

O projeto pode ser publicado em Vercel, Netlify, GitHub Pages ou qualquer serviço compatível com aplicações Vite. Para gerar os arquivos finais, execute `npm run build` e publique a pasta `dist/`.
